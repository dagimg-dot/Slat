# Slat

<p align="center">
  <img src="assets/icon.png" alt="Slat Logo" width="200">
</p>

Slat is an intuitive edge panel for Android that streamlines your mobile experience. It provides instant access to essential tools and information right from the edge of your screen, designed for speed and ease of use. (Currently only supporting clipboard access)

## Features

- **Global Toggle**: to enable and disable slat
- **Clipboard with Text and Image Support**: A clipboard manager that captures and previews both text snippets and images, keeping your most important data just a swipe away.
